# GalFlow 🌸 | 视觉小说与 Galgame 剧本整理工坊

> 专为视觉小说（Visual Novel）与 Galgame 创作者打造的轻量级、零依赖、纯本地运行的剧本整理与无限画布流程图工具。

---

## 🌟 核心特性

- 🎨 **类似“无边记”的无限画布**：
  - 支持画布空白处拖拽平移、滚轮平滑缩放（20% ~ 250%）。
  - 卡片节点自由排布，支持按住 `Shift` 拖拽框选多个节点进行批量平移与快速建组。
- 📖 **多级 Markdown 剧本智能导入**：
  - 递归识别任意 `H1 ~ H6` 多级标题，文档中的每一个大纲层级（篇、章、幕、场、节）均单独生成独立卡片。
  - 自动提取 Galgame 剧本元数据（指定场景地点、出场角色、配乐 BGM、台词对白以及分支选项）。
- 🏷️ **智能层级框选（Group Containers）**：
  - 导入多级大纲时，自动为各章节生成半透明磨砂分组大框，并标注层级 Badge。
  - 采用**阶梯式分行横向流水线排版**，不同分组在垂直方向上错落展开，彻底杜绝分组框重叠碰撞。
- 🔗 **横向左右剧情连线与分支逻辑**：
  - 节点连线严格采用**左侧入口（In）与右侧出口（Out）**的水平贝塞尔平滑流线。
  - 每个分支选项拥有专属输出端点，连线中点自动附带选项文本或条件标签（如 `好感度+10`），支持点击断开确认。
- ☀️ **日间暖白 / 🌙 夜间暗色双主题**：
  - 右上角胶囊式双态切换器，清晰直观。
  - **日间暖白**：采用柔和护眼的和纸暖白色调（`#f6f4ee`），适合长时间剧本撰写。
  - **夜间暗色**：沉浸式深黑设计（`#12141a`），夜间使用不刺眼。支持浏览器本地偏好自动记忆。
- 🌐 **全景横向半透明小地图**：
  - 磨砂毛玻璃半透明质感，不遮挡底层卡片。
  - 针对超长横向时间线优化，长条微缩图在小地图中自适应垂直居中对齐，支持一键切换宽屏展开模式。
- 💾 **纯本地安全运行与离线导出**：
  - 100% 运行于浏览器本地，无任何外部服务器传输，充分保护剧本隐私。
  - 支持一键导出/导入完整工程 `.json` 文件。
  - 内置防丢失机制，编辑时实时同步至浏览器本地缓存（`localStorage`）。
  - 支持一键导出整部作品的完整结构化 Markdown（`.md`）剧本文档。
